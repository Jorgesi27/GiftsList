# GiftsListIW

Jorge Antonio Sánchez Benítez.

Proyecto final para IW. Aplicación web sobre listas de regalos.

Aplicación web responsive para la creación y gestión de listas de regalos, desarrollada con Java, Spring Boot , Vaadin
y MySQL. El sistema permite registrar y autenticar usuarios mediante confirmación por correo electrónico, gestionar
personas allegadas y crear listas de regalos asociadas a diferentes ocasiones, incluyendo el seguimiento del estado de
cada regalo, precios y enlaces externos. La aplicación incorpora además un resumen de las listas con el coste total y su
estado de compra, facilitando la organización y seguimiento de los regalos.
